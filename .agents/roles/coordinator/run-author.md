# X-Autor ausführen

Diese Datei bleibt für frühere Aufrufe erhalten. Der allgemeine Prozess für einzelne Rollen steht in `run-role.md`.

## Eingang

Ein ausdrücklicher Auftrag nennt genau einen veröffentlichten Blogartikel.

## Ablauf

1. `.agents/roles/autor/AGENTS.md` vollständig lesen.
2. Nur den Autor mit dem genannten Blogartikel aufrufen.
3. Den eigenen Durchgang nach `../../conventions/evolution.md` auswerten und
   nur relevante neue Erfahrung gegenstandsbezogen unter `lernen/` festhalten.
4. Danach stoppen und den erzeugten Entwurf melden.

## Grenzen

- Editor und Herausgeber nicht aufrufen.
- Kein Commit oder Push.
